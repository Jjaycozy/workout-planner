# 6-Week Workout Planner

A Progressive Web App (PWA) for tracking your workout journey over 6 weeks.

## Features

- 📅 6-week workout planning interface
- 💪 Daily workout cards for Monday-Sunday
- 💾 Automatic data persistence (localStorage)
- 📱 PWA - Install on your phone like a native app
- 🎨 Beautiful purple and pink design
- ✨ Works offline

## Tech Stack

- React + TypeScript
- Tailwind CSS v4
- Vite
- PWA (Progressive Web App)

## Development

```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build for production
pnpm build
```
